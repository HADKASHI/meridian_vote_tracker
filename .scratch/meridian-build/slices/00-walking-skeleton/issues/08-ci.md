# 08: CI

**What to build:** every push and pull request runs three parallel jobs. `backend` builds with warnings as errors, fails when the build changes `contracts/openapi.json` or the model has pending changes, and runs the domain and integration tests with Testcontainers. `web` installs, generates the client, lints, tests and builds. `compose` brings the stack up with the synthetic member states, checks the web page and one authenticated `/api` call through nginx and that `migrate` exited 0, prints logs on failure and always tears down. `RealData` and `Performance` tests never run here.
